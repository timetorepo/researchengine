# Brand: how ResearchEngine names the world's models

ResearchEngine is an independent product. It routes to many AI providers
(OpenAI, Anthropic, Google, xAI, Mistral, Meta, NVIDIA NIM, OpenRouter and
more), and the point of this document is that we can talk about all of them
without becoming any of them.

## The rule: nominative use, zero ornament

- Provider names appear as plain text, exactly as the company writes them
  ("Claude", "GPT", "Gemini", "Grok"). Never stylised, never in our headlines,
  never in our logo lockups.
- No provider logos in our chrome, marketing, or release art. The small marks
  shown next to a model in chat are rendered from the provider's own public
  mark *inside the product* to identify whose answer you are reading; they are
  never used to advertise ResearchEngine itself.
- Our own feature names are ours: Research Engine, AIFlowEngine, Sessions,
  Personas, the Rankings boards. We do not reuse product names like "Codex",
  "ChatGPT", "Claude Projects" or "Gemini Apps" for features. A persona may be
  *of* Codex; it is never *called* Codex.
- Every surface that lists providers carries the standing line:
  "Independent product. Not affiliated with, endorsed by, or connected to any
  provider unless they say so."

## Why this is safe

Nominative use (naming another product to say something true about it) is the
ordinary way comparison and compatibility are communicated. What creates risk
is decoration: logos in hero sections, name-alike features, trade dress. We
keep the names, drop the ornament, and keep our own visual language
(squircles, glass, springs) distinct from every provider's.

## Transfer guides

Users arrive from other AI products, so Settings → About names the mappings in
their vocabulary instead of making them learn ours:

| They know                    | They get here                          |
| ---------------------------- | -------------------------------------- |
| ChatGPT conversations        | Sessions (Alt+Shift switcher)          |
| GPTs / custom instructions   | Personas + custom system prompts       |
| Claude Projects / knowledge  | Library spaces + attached sources      |
| Codex / agent mode           | Coding workspace + agent pool          |
| reasoning effort / thinking  | the Effort ladder + Chain of thought   |
| GPT store / tools            | Skills + MCP Servers                   |
