# Research Engine 1.10.0 — Native Studio and searchable settings

## What's new
- **Search individual settings.** Find controls such as Dynamic Island, keyboard,
  density and font family. Results show their category and bring the selected
  setting into view. Likely misspellings offer an explicit “Do you mean…?” action.
- **Native Studio.** Warm graphite surfaces, compact shared controls, grouped
  settings, and locally bundled Allo typography. Existing font, density and layout
  preferences are preserved; Allo is the fresh-profile default.
- **Cleaner live status.** The MIT islandcn engine replaces the previous island
  renderer and uses real streaming, search, agent, skill and focus activity.
- **Consistent identity.** The selected ResearchEngine mark appears throughout
  the application and desktop packaging. Clicking the app logo returns Home.
- **Branded Windows setup.** Original sidebar/header artwork, clearer welcome and
  finish copy, matching installer/uninstaller icons, and opt-in launch/shortcut
  choices, while retaining Tauri's per-user, upgrade and WebView2 handling.

## Fixes and accessibility
- Removed nested notification buttons in collapsed navigation.
- Improved shared input labels/help and invalid-state associations.
- Added keyboard-operable density controls and compact accessible switches.
- Removed unconditional animated waves behind reading surfaces.
- Reduced-motion users see a static launch identity instead of the shader intro.

## Upgrade notes
Your existing chats, library, saved settings and model configuration remain in
place. No manual data deletion is required. Floating navigation and the activity
island retain their existing preferences. Windows may need to download WebView2
if it is not present. Connected model services keep their own privacy terms.

## Known limitations
- Headless browser tests are not native WebView, screen-reader or physical-device
  certification. Interactive Windows DPI/upgrade/uninstall checks remain manual.
- The full-motion first-launch intro still has measured frame-time/GPU stalls;
  isolated settings interactions are substantially faster than that full-launch
  scenario, but universal 60fps is not claimed.
- Large-chunk and existing dynamic-import build warnings remain.
- Settings search uses a local control-label index, not remote semantic search.

## Validation
TypeScript, production frontend/backend build, component checks, targeted settings
search and island browser checks, and desktop asset structure checks were run.
Windows/Linux installer compilation and boot/bundle checks are release gates;
CI outcome is recorded with the release after those jobs finish.
