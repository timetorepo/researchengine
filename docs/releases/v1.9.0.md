# Research Engine 1.9.0

## Local image editing
- Upload a profile photo, crop it square with a circular preview, and restore your generated avatar at any time.
- Crop, straighten, rotate, flip and zoom image uploads using the MIT-licensed zriz editor, processed locally.
- Shared editor for chat attachments, appearance backgrounds, wallet artwork, local article images and quiz/share imagery.
- Non-avatar uploads offer **Use original**, preserving the original file and animations. Applied crops export a still PNG; profile photos export at up to 512 × 512 pixels.
- No arbitrary image-upload MB cap added. Browser decoder, memory, storage and selected model/provider limits still apply. Chat retains its three-image limit.

## Integrated workspace controls
- Searchable settings modal that preserves your working context and existing preferences.
- Marketplace filter drawer, tool accordions, service connection controls and shared selection controls.
- Local notification center with unread/category filters and time grouping.
- Local document intake with approximate extracted-text token estimates, actual extraction progress and explicit import/draft actions.
- Calendar date picker, windowed Coding file tree, stepped clarification questions, and execution logs connected to actual agent tool states.
- Shared operation progress presentation for updates, downloads and setup.

## Downloads and verification

Local TypeScript, production build, component checks and actual browser image-crop/export/persistence/cancellation/recovery checks passed. Native interactive installation and physical-device/screen-reader verification were not performed. No macOS installer is supplied by this workflow.

## Known limitations
- Cold settings-open performance remains under investigation: the documented headless production run measured a 150ms p95 frame interval. Warm scenarios were near the 60Hz budget; this is not universal 60fps certification.
- Crop Apply produces a still image; use **Use original** to retain animation for non-avatar uploads. SVG cropping is disabled.
- Browser storage/resource limits and provider image limits remain relevant. Huge-image stress testing and native WebView gesture validation were not performed.
