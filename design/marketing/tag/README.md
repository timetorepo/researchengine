# ResearchEngine production signature

Original supporting marketing artwork, not a replacement installer/app logo. The user's monochrome Acre reference informed negative space and the production-label composition; its logo, coordinates, domain and registration symbol are not reused. RE 01 is an artwork edition stamp, not a registered-trademark claim or software release number.

Two standalone SVG and PNG exports: graphite and warm paper. SVG lettering is outlined (Geist Mono, SIL OFL 1.1; licence alongside). The symbol is the selected app symbol from lib/brand.ts. SVGs include accessible titles/descriptions. No network fonts or embedded external images. No UI placement changed.

Rebuild SVG: see tools/design/make-brand-tag.py. PNG renders are browser rasterizations at 1600 × 1200; no image-generation model was used. Software fonts are not embedded in these SVGs.
